非官方的 [Bangumi 番组计划](https://bgm.tv) Windows 桌面客户端，使用 Kotlin 与 Compose Multiplatform 编写的学习项目。这是第一个公开发布的版本。

## 功能

- **搜索**：按类型筛选（全部 / 动画 / 书籍 / 音乐 / 游戏 / 三次元），按匹配度、收藏人数、排名或评分排序；每个结果标出“动画 · TV”“书籍 · 漫画”等类型和日期。
- **索引**：按类型、分类（如 TV、剧场版、漫画、小说）、年份、月份浏览条目，按排名或日期排序。
- **条目详情**：评分与排名、10 档评分分布、放送信息、收藏统计、简介、主要人物、吐槽。
- **角色详情**：中文名、基本资料、简介、声优、出演作品；可以在条目和角色之间来回浏览。
- 封面、头像与角色立绘；搜索结果和吐槽可以“加载更多”；详情页按 Esc 返回上一页。

## 安装

1. 下载下方的 `Bangumi-1.1.0.msi`（约 59 MB），双击安装。
2. 默认安装到当前用户目录（`%LOCALAPPDATA%\Bangumi`），不需要管理员权限；开始菜单和桌面会有快捷方式。
3. 安装包自带 Java 运行环境，不需要另外安装 Java。
4. 安装包没有数字签名，Windows 可能提示“Windows 已保护你的电脑”，可以点“更多信息”→“仍要运行”。
5. 卸载：在系统设置的“已安装的应用”中卸载；卸载前请先关闭程序。

在 Windows 11（64 位）上测试；使用时需要联网。

## 说明

- 数据来自 Bangumi 公开 API。吐槽使用 Bangumi 新版网页的非公开接口，可能随时变化；失效时只影响吐槽区域。
- 不需要登录，也不会读取或修改你的 Bangumi 账户数据。
- 本项目与 Bangumi 官方无关。
